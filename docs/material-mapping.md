# 材料对照表与版本

所有原文集中在 `src/config/content.ts`，页面组件只消费配置，不散落文案。收到材料更新时新建版本，不在 `flow-v1` 内静默修改；旧样本保留原版本号，后台支持按版本过滤。

## 流程修订记录

`flow-v2`（2026-10-25）按项目负责人的新要求实现，新要求优先于原《流程》及之前开发提示词中的冲突规定：

- 八组统一流程为：知情同意 → 历史记录 → 权限告知 → 购买任务 → 推荐结果 → 问卷 → 结束。
- `scope` 只控制权限告知页内容：scope=1 展示“仅最近一次会话”，scope=2 展示“最近一次会话 + 更早会话全部内容”；设置为既定范围告知，不要求被试重新授权。
- `remind` 只控制推荐页顶部文案：remind=1 展示历史偏好提醒，remind=0 展示普通推荐提示。
- 权限页说明“系统可以访问什么”，推荐页提醒说明“本次推荐参考了什么”，不再把两个因素合并处理。
- `flow-v1` 已提交记录保持原样，不回填权限页展示状态，也不伪造停留时间；后台按版本区分。

`flow-v3`（2026-10-25）在 `flow-v2` 基础上仅调整推荐页呈现方式：

- 推荐页改为固定的中文购物助手对话：预填任务由受试者点击“发送”后展示，助手以相同开场回复并列出原 A/B/C 三款商品。
- `scope` 仍只控制权限告知页内容；`remind` 仍只控制推荐回复中的提醒文案，二者独立。
- 问卷受试者分节标题改为“使用体验 / 体验回顾 / 日常使用”，题目原文、题序、5 点选项和编码不变。
- 任务发送、助手回复展示、进入问卷的时间仅写入当前页签 `sessionStorage`，未提交不持久入库。

## 页面原文对照

| 页面 | 路由 | 配置键 | 流程原文 |
| --- | --- | --- | --- |
| 知情同意 | `/start` | `CONSENT_CONTENT` | 标题“实验知情同意书”、三段说明与按钮“我已阅读并同意，开始实验” |
| 历史记录 | `/records` | `HISTORY_CONTENT` | “与智能体历史聊天记录（模拟）”，两个时间分区、7 条模拟消息、备注“以上对话纯属虚构。”、按钮“下一步” |

| 购买任务 | `/task` | `TASK_CONTENT[1/2]` | goods=1 笔记本电脑任务文案；goods=2 电脑包任务文案；按钮“查看推荐” |
| 推荐结果 | `/recommend` | `RECOMMENDATION_CONTENT` | 对话界面：任务消息由受试者发送；助手开场、提醒文案按条件固定；商品按 A、B、C 固定顺序；按钮“前往问卷填写” |
| 问卷 | `/questionnaire` | `QUESTIONNAIRE_CONTENT` | 指导语、15 题、受试者分节名“使用体验 / 体验回顾 / 日常使用”、5 点同意度、按钮“提交” |
| 结束 | `/done` | `END_CONTENT` | “感谢你完成本次实验！”与“本次实验到此结束。” |
